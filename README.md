# ISIHLANGU - GBVF Safety Solution for KZN

## The Problem
High-risk township and rural areas lack connectivity and physical security. 

## Our Solution
An offline risk-detection smartwarch powered by a Raspberry Pi Pico 2. 
It detects a scream by the user via a trigger word and sends an immediate alert signal to the users Emergency contacts and if the user is still under duress after 10 seconds the community forums and other emergency personal nearby will be alerted.

## Hardware Used
* Raspberry Pi Pico 2
* Analog Sound Sensor Module
* 5V Active Buzzer / LED
* Breadboard & Jumper Wires
